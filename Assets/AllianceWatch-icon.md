# AllianceWatch application icon

Created with the built-in image generation tool. `AllianceWatch.png` is the original
generated artwork with transparent corners. `AllianceWatch.ico` contains 16, 24,
32, 48, 64, 128, and 256 pixel PNG frames for Windows. The artwork is embedded in
the application, so deployment does not depend on an external icon file.

## Generation prompt

Use case: logo-brand. Create one polished Windows desktop application icon for AllianceWatch, a strategic public-news monitoring and evidence assessment app. Square 1024 x 1024 PNG with genuine transparency outside the icon. A near-black navy rounded-square tile fills about 92% of the canvas, with restrained teal edge treatment. In the center, an exceptionally clear bold geometric AW monogram in luminous pale cyan, integrating a simple radar arc around the monogram and a single small amber signal dot on the upper-right arc. The only text is the two letters AW, accurate and highly legible. Match a dark monitoring-console identity: near-black #02080A, dark teal #061B1F, vivid cyan #35DEE0, pale cyan #9BFFFA, and one amber #FFA439 accent. Modern precise graphic design, strong simple silhouette, substantial strokes, sharp clean edges, minimal flat shapes with only subtle tonal depth. Must read clearly at 16, 32, and 48 pixels. Straight-on, centered and symmetrical optical balance, generous separation between the A and W, no thin grid lines or tiny detailing. Deliver the finished single icon itself, not an icon sheet or mockup. No app-name caption, no watermark, no weapons, no flags, no photorealism, no perspective, no long cast shadow, no white background.
