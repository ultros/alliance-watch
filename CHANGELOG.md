# AllianceWatch changes

## 2026-10-01

- Added a manual Compress Database action with progress, verified backup, full
  image-content rehashing and relinking, orphan-payload cleanup, and compaction.
  Collection pauses and resumes around maintenance; article-image metadata is retained.
- Restored missing configuration from bundled defaults without replacing user
  settings or databases. Published launches use the executable's archive folder.
- Allowed free use, modification, and free sharing of AllianceWatch with attribution,
  including internal business use. Selling copies or derivatives, paid bundles,
  and paid hosted access require the owner's paid written permission.
  The free-use grant also covers earlier versions published by the owner.
- Added creator and copyright-owner details, with LinkedIn
  and GitHub repository links in the app, source, and citation metadata.
- Added a permanent attribution banner, source-file license notices, distributable
  license and attribution files, and GitHub citation metadata.
- Made image deduplication automatic for new downloads and existing archive images,
  using hashes of original image bytes and preserving every article-image link.
- Kept gallery article inspection working during background image conversion.

Earlier changes and their authors are recorded in the repository's Git history.
Authorized contributors should document subsequent modifications and their dates here.
